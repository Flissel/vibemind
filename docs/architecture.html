System architecture

A modular agentic workspace with a separate cognitive control plane, governed execution boundary, domain Spaces, and evidence-producing data services.

Architecture contract: Brain decides and plans. OpenFang resolves, approves, and executes. Missing authority fails closed.

Request pipeline

1. NormalizeIngress supplies intent, context, and correlation data.
2. DecideBrain classifies, plans, and selects a capability.
3. GovernContracts and policy reject invalid or unauthorized work.
4. ResolveOpenFang resolves the canonical agent and approval scope.
5. ExecuteThe agent calls only allowlisted MCP tools or applications.
6. ProveStructured results and terminal evidence return to the caller.

Trust and data boundaries

Authority

Ingress requests work; Brain decides; OpenFang authorizes and executes; a Space proves terminal state.

Data

Supabase, coding stores, Rowboat Mongo/Qdrant, MiroFish Neo4j, n8n data and media artifacts retain distinct owners.

External effects

Desktop actions, messages, workflow runs and publication need explicit authority and external receipts.

Evidence boundary
