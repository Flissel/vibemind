# Support

VibeMind is a community project under active development. Support is provided on
a best-effort basis.

## Before asking for help

1. Read the [README](README.md) and component-level documentation.
2. Confirm all submodules are initialized with
   `git submodule update --init --recursive`.
3. Run the relevant command with `-DryRun` when supported.
4. Remove secrets and personal data from logs and screenshots.
5. Search existing GitHub issues for the same symptom.

## Where to ask

- Use a GitHub issue for a reproducible bug or setup problem.
- Use a feature request for a concrete improvement proposal.
- Use the component's own repository when the problem is isolated to a
  submodule.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities or exposed credentials.

Include your operating system, Python/Node/Docker versions, the root commit ID,
relevant submodule commit IDs, the command you ran, expected behavior, actual
behavior, and a minimal sanitized log.

General consulting, deployment operations, account recovery, and guaranteed
response times are outside the community support commitment.
